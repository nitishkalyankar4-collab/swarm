# Pre-Trade Memo Template & Telegram HTML Rules (v17.0.0)

This reference outlines the required output structure for institutional signals generated by `/swarm`, incorporating metrics across **CCXT**, **VectorBT**, **pandas-datareader**, **OpenBB**, **Agent Reach**, **Firecrawl**, **Crawl4AI**, and **LangGraph**.

---

## 1. Telegram HTML Formatting Requirements

Telegram bot messages generated by `/swarm` must use `parse_mode=HTML`.
- Bold text: `<b>Text</b>` (Do NOT use `*text*`)
- Monospace / Code: `<code>Text</code>` (Do NOT use backticks)
- Code blocks: `<pre>Text</pre>`
- Timestamps: Always in **IST** format.
